# CPI Practice Artifacts

SAP Cloud Integration practice projects. Each project folder contains its own README, iFlow, and any supporting resources.

- [Calculator 2](<Calculator 2/README.md>) - HTTP-to-SOAP calculator flow and message mappings.
- [Content modifier](<Content modifier/README.md>) - Content Modifier palette practice.
- [CSV to XML converter](<CSV to XML converter/README.md>) - Convert CSV employee data to XML using an XSD.
- [Encoder and Decoder practice iflow](<Encoder and Decoder practice iflow/README.md>) - Base64 and ZIP/GZIP encoding and decoding.
- [Exception Sub Process practice](<Exception Sub Process practice/README.md>) - Exception subprocess and error handling practice.
- [Filter palette functions practice IFLOW](<Filter palette functions practice IFLOW/README.md>) - Filter employee XML using several conditions.
- [Ifow for router pallette functions](<Ifow for router pallette functions/README.md>) - Route messages based on country.
- [Join and Gather pallette functions practice iflow](<Join and Gather pallette functions practice iflow/README.md>) - Split, join, and gather employee messages.
- [Local integration process practice](<Local integration process practice/README.md>) - Call local integration processes and practice split processing.
- [Looping process call practice](<Looping process call practice/README.md>) - Looping process calls with a message counter.
- [PGP Encryptor and Decryptor Iflow](<PGP Encryptor and Decryptor Iflow/README.md>) - PGP encryption and decryption practice.
- [Splitters_Practice Iflow](<Splitters_Practice Iflow/README.md>) - General and iterating splitter examples.
- [Task on Content modifiers](<Task on Content modifiers/README.md>) - Content Modifier exercise.
- [Test Iflow](<Test Iflow/README.md>) - SOAP-based test integration flow.
- [XML Modifiers](<XML Modifiers/README.md>) - XML Modifier practice with sample payload.
- [XML modifiers practice Iflow](<XML modifiers practice Iflow/README.md>) - XML payload modification practice.
- [XML to JSON conversion practice](<XML to JSON conversion practice/README.md>) - Compare streaming and non-streaming XML-to-JSON conversion.
