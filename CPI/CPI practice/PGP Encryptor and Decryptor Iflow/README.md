# PGP Encryptor and Decryptor Practice

An integration flow demonstrating PGP encryption and decryption steps with an initialized sample message.

The exported flow contained a literal passphrase, which has been replaced in this repository copy by `CONFIGURE_IN_SECURE_PARAMETER`. Configure the required public/private keys and passphrase using SAP Integration Suite security material or secure configuration before deployment. Do not commit credentials or private keys.
