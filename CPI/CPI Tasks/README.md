# CPI Task Artifacts

SAP Cloud Integration task projects. Each project folder contains its own README, iFlow, and any supporting resources.

- [Employee Details Integration_HTTP to Email](<Employee Details Integration_HTTP to Email/README.md>) - Validate employee JSON received over HTTP and send an email.
- [Northwind Product Price Alert OData Integration](<Northwind Product Price Alert OData Integration/README.md>) - Fetch Northwind products, select prices above 50, and email an alert.
- [Sales Order Validation and External API Integration](<Sales Order Validation and External API Integration/README.md>) - Validate and enrich sales orders, map them, and call an external REST API.
